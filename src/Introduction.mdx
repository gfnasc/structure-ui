# Welcome to StructureUI: The Headless Behavior Engine

StructureUI is not a traditional UI library. It's a **headless behavior engine** for Vue 3 and Nuxt, designed to provide complex UI logic, accessibility, and performance optimizations without imposing any visual style.

## Core Philosophy

1.  **Behavior, Not Looks**: We provide the "how" (logic, state, ARIA), you provide the "what" (CSS, classes, design). Every component is a blank slate for you to style.

2.  **Performance First**: Built-in lazy hydration, virtual scrolling, and SSR-safe components ensure your app is fast by default. We handle the hard parts of performance so you can focus on features.

3.  **Accessibility as a Foundation**: Focus traps, ARIA attributes, and keyboard navigation are baked into our components. Building an accessible application is non-negotiable.

## Getting Started

To use a component, import it and apply your own styles. StructureUI components accept any standard HTML attributes, including `class`.

```vue
<script setup>
import { Button } from 'structure-ui';
</script>

<template>
  <Button class="px-4 py-2 bg-blue-600 text-white rounded hover:bg-blue-700">
    Click Me
  </Button>
</template>
```

## Hydration Best Practices

- **`useStructureId`**: Always use this for generating unique IDs to prevent mismatches between server and client.
- **`LazyHydrate`**: Wrap non-critical components (like footers or comment sections) to defer their loading and improve Time to Interactive.
- **`AsyncBoundary`**: Use this to handle loading and error states for any component that fetches data.
